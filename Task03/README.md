# Task 03 – Campus Library Search Screen

## Compile and run
```bash
javac -d out src/*.java
java -cp out LibrarySearchScreen
```
The Swing screen contains a title, search row, category selector, search button, central results table, Prev/Next/Reserve controls and status message. The results area occupies the centre of a BorderLayout and expands when the frame is resized.

`DESIGN_NOTES.md` documents layout choices, nested containers, resizing behaviour and the alternative layout/complexity comparison.
